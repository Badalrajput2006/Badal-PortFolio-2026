# Badal Rajput — Developer Portfolio

A modern developer portfolio built with:

- React
- Vite
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Profile image

The portfolio expects:

`public/Badal Profile Pic.jpeg`

The supplied profile photo has already been placed in the project.

## Before deploying

Add the resume PDF later if you want a Resume button. The current version intentionally does not point to a fake/missing resume file.

## Deployment

This can be deployed to Vercel, Netlify or GitHub Pages. For Vercel, the default Vite settings are sufficient.
